How this actually blocks. A web page can’t force-close apps on your phone — only the OS can do that. This runs the commitment: the clock keeps counting even if you close the tab, and it logs every time you leave. For a hard block, arm the same list in Screen Time → App Limits (iOS) or Digital Wellbeing → Focus mode (Android) and start both together.
The countdown is stored by end time, not by a running tab — refreshing, closing, or force-quitting this page will not give you the time back.
